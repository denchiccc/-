# АВТОПИЛОТ ГЕНЕРАЦИИ 3D-ФУРНИТУРЫ ДЛЯ БАЗИС-МЕБЕЛЬЩИКА

Когда пользователь присылает в чат изображение (чертеж с размерами, эскиз, схему из каталога) или текстовое описание детали, ты ОБЯЗАН без дополнительных вопросов выполнить полный цикл до готового 3D-файла:

1. АНАЛИЗ И ВЫБОР ДВИЖКА:
   - По умолчанию (для стяжек, опор, петель, направляющих, профилей, полкодержателей) используй Python-окружение `.venv\Scripts\python.exe` с библиотекой `build123d` и экспортируй в `output/<имя_детали>.step`.
   - Если на чертеже сложная дизайнерская лицевая фурнитура с плавными формами (ручки, крючки, декор) или пользователь явно указал Blender — используй найденный путь к `blender.exe` в фоновом режиме (`blender.exe -b -P ...`) и экспортируй в `output/<имя_детали>.dae` (Collada).

2. ПРАВИЛА ПОСТРОЕНИЯ МОДЕЛИ (КРИТИЧЕСКИ ВАЖНО ДЛЯ БАЗИСА):
   - Точность: Строй геометрию строго по размерам в миллиметрах (мм) с чертежа.
   - Иерархия (Структура): ЗАПРЕЩЕНО сливать всю фурнитуру в одно тело! Каждая логическая деталь (например: `Korpus`, `Shtok`, `Planka`, `Vint`, `Zaglushka`) должна создаваться отдельным объектом со своим понятным именем на латинице (`label`).
   - Покраска (Цвета): Обязательно назначай реалистичные цвета каждому элементу:
     * Сталь / Хром: `(0.75, 0.75, 0.78)`
     * Цинк / Матовый алюминий: `(0.60, 0.62, 0.65)`
     * Черный пластик / Муар: `(0.15, 0.15, 0.15)`
     * Латунь / Золото: `(0.85, 0.65, 0.20)`
   - Шаблон кода для `build123d` (сохраняет структуру и цвета в STEP):
     Всегда оборачивай отдельные детали (объекты `Part` с заданным `.label` и `.color = Color(...)`) в единый корневой узел `assembly = Compound(label="Furnitura_Assembly", children=[part1, part2, ...])` и вызывай `export_step(assembly, "output/name.step")`.

3. ФОНОВЫЙ ЗАПУСК И САМОИСЦЕЛЕНИЕ (SELF-HEALING):
   - Сохрани написанный скрипт в `scripts/build_<имя>.py`.
   - САМ запусти его через терминал.
   - Если в терминале возникла ошибка (Traceback), НЕ СПРАШИВАЙ пользователя! Сам прочитай ошибку, исправь код скрипта и перезапусти его. Повторяй цикл отладки, пока файл в папке `output/` не будет успешно создан.

4. ОТЧЕТ ПОЛЬЗОВАТЕЛЮ:
   Выведи короткое сообщение:
   - "✅ Готово! Файл для Базиса: `output/<имя_файла>`"
   - Список созданных узлов структуры (и их цвета).
   - Габаритные размеры (X, Y, Z) для проверки.
