# Автопилот генерации 3D-фурнитуры для Базис-Мебельщика

Автоматизированный конвейер создания параметрических 3D-моделей фурнитуры, наполнения и бытовой техники для САПР **«Базис-Мебельщик»** с использованием Python (`build123d`) и экспортом в формат STEP с сохранением иерархии деталей и цветов.

---

## 📐 Правила позиционирования и оси координат (Базис)
Все модели ориентированы строго по габаритной рамке Базис-Мебельщика:
- **X — Ширина** (слева направо)
- **Y — Высота** (снизу вверх, основание на $Y = 0$)
- **Z — Глубина** (вглубь / на зрителя)

---

## 📁 Структура проекта
- `scripts/` — Python-скрипты генерации компонентов через библиотеку `build123d`.
- `output/` — Готовые 3D-файлы моделей (`.step`) для импорта в Базис-Мебельщик.
- `AGENTS.md` — Инструкции и системные промпты агента для генерации фурнитуры.
- `config.json` — Пути к локальным интерпретаторам Python, Blender и FreeCAD.

---

## 🚀 Запуск скрипта генерации
```powershell
.venv\Scripts\python.exe scripts/build_<имя_детали>.py
```
Скрипт автоматически собирает модель в корневой узел `Compound` и сохраняет результат в папку `output/<имя_детали>.step`.
